# Midnight Synth — GitHub Pages

1. Copy your four Arial Narrow .ttf files into `fonts/`, preserving exact filenames.
2. Upload the **contents** of this folder (not the enclosing folder) to the root of your GitHub repository.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Open your Pages URL in Safari/Chrome and tap PLAY. Sound cannot autoplay on phones.

File layout:
- index.html
- styles.css
- fonts.css
- script.js
- .nojekyll
- fonts/Arial Narrow.ttf
- fonts/Arial Narrow Bold.ttf
- fonts/Arial Narrow Italic.ttf
- fonts/Arial Narrow Bold Italic.ttf

All paths are relative. No external CSS or JavaScript CDN is needed.
